# Editorial Feature Mosaic — Validation Notes

The desktop Portfolio uses an explicit 4 × 16 occupancy map. Five selected image features interrupt the regular cell field in distinct ways: Portfolio 02 is a tall one-column portrait, Portfolio 14 is a two-column by three-row portrait feature, Portfolio 17 is a low two-column landscape, Portfolio 35 is a three-row portrait interruption, and Portfolio 54 is a low two-column landscape. These feature regions occupy fifteen cells and three individually placed standard images occupy another three; the remaining forty-six standard images precisely fill the other forty-six cells. The field therefore has no empty or overlapping desktop cells.

The preview treatment uses `object-position: center center` on every image. The 02 feature maintains the complete model from head to feet without the rejected square crop; the 14 feature breaks two local baselines; the 17 and 54 features remain visibly landscape. The full viewer was tested from Portfolio 02: it opened the uncropped original, ArrowRight advanced to the next native source, and Escape returned to the gallery. At the phone breakpoint, explicit desktop placement is intentionally reset so all 54 images render within the responsive two-column field with the same fixed 18px gutter and no off-screen implicit columns.
